# Ide narasi ebook

## Mengapa saya menggunakan claude code?

Ada setidaknya 2 hal yang dimiliki claude code tapi tidak dimiliki oleh LLM berbasis chat manapun (chatGPT, gemini, bahkan Claude web), yaitu:
1. kemampuan read, write, dan edit file 
2. konteks dan memory yang sangat fleksibel

Kedua hal itu saja sudah jadi nilai tambah yang sangat besar dan cukup untuk menjadi alasan penggunaan claude code untuk project menulis artikel yang membutuhkan berulang kali pengeditan.

Meskipun demikian, penggunaan claude code juga memiliki dinding pembatas, khususnya bagi yang awam dengan dunia coding. Jika dipaksakan, maka bukannya malah jadi produktif, malah progress tidak akan maju-maju karena mempelajari sesuatu yang tidak perlu. Kalaupun bisa, penggunaannya tidak akan optimal, baik dari segi ekonomi (penggunaan token) maupun kualitas hasil yang diperoleh.

Oleh karena itu, disinilah ARTi Framework menjadi solusi dan setidaknya menurunkan ketinggian dinding tersebut. Effort masih tetap diperlukan untuk mempelajari claude code, tetapi sudah jauh lebih dipermudah apalagi dibantu dengan adanya instruksi penggunaan yang terstruktur.

Selain kedua alasan di atas, masih ada banyak kelebihan lain jika menggunakan claude code, di antaranya adalah:
- mudah diintegrasikan dengan python untuk mengerjakan berbagai proses, seperti membuat grafik, konversi markdown ke pdf atau docx, melakukan analisis statistik, dan lain sebagainya
- semua file input dan output ada dalam 1 folder, tidak perlu download, upload banyak file untuk memberi konteks maupun mengambil hasil
- Mudah diintegrasikan dengan skill, sehingga hasil lebih optimal
- dan masih banyak lagi (bisa diturunkan berdasarkan berbagai fitur pada ARTi framework, misal dari fitur untuk landing page)
