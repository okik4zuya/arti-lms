# Solusi dari Masalah Saya Selama Ini (Mungkin Anda Juga)

Di penutup bagian [[Claude Code]], saya bilang begini: punya alat yang tepat saja belum cukup.

Supaya memori benar-benar persistent dan terstruktur, saya butuh sesuatu yang lebih dari sekadar tools.

Saya butuh sebuah sistem.

Mari saya rangkum dulu, supaya jelas benang merahnya.

## Menegaskan lagi masalahnya

Dari [[2 Masalah Utama]], saya cerita ada dua hal yang bikin saya tidak puas dengan AI selama ini: halusinasi, dan hilangnya memori antar sesi.

Dari [[Claude Code]], saya menemukan alat yang menjawab sebagian besar keluhan itu — kontrol file yang leluasa, memori yang bisa diatur sendiri, cocok untuk iterasi jangka panjang.

Tapi ada satu celah yang belum saya tutup.

Claude Code itu hebat sebagai mesin. Tapi mesin saja tidak tahu ke mana harus melangkah.

Ia bisa membaca dan menulis file apa saja, sesuka saya. Tapi file apa yang harus dibuat, disusun bagaimana, disimpan di mana, dibaca kapan — itu semua tidak datang otomatis dari Claude Code sendiri.

Kalau saya cuma asal menyimpan catatan di sana-sini tanpa aturan, ya sama saja seperti sebelumnya: berantakan, sulit dicari lagi, dan pada akhirnya kembali hilang begitu saja.

## Perkenalkan: ARTi Framework

Jadi, jawaban saya bukan sekadar "pakai Claude Code".

Jawaban saya adalah cara kerja yang saya susun sendiri di atas Claude Code — struktur folder, aturan menulis, dan kebiasaan yang konsisten saya pakai setiap kali menulis artikel ilmiah.

Saya namai ini ARTi Framework.

Bukan tools tambahan yang perlu diinstal terpisah. Bukan juga produk siap pakai yang tinggal klik lalu semuanya beres.

Ini lebih tepat disebut metodologi — cara kerja yang saya susun sendiri, di atas alat yang sudah ada.

## Mungkin Anda juga

Saya sadar, cerita di dua bab sebelumnya itu sangat personal. Riwayat saya mencoba berbagai AI, pengalaman saya jatuh cinta pada Claude, keluhan saya soal memori yang tercampur.

Tapi saya cukup yakin, ini bukan cuma keluhan saya sendiri.

Kalau Anda pernah mencoba serius menulis artikel ilmiah dibantu AI — bukan sekadar tanya jawab singkat, tapi benar-benar mengerjakan naskah yang panjang, berbulan-bulan, direvisi berkali-kali — saya rasa Anda pernah, atau akan, mengalami hal yang sama.

Halusinasi yang menyelinap di tengah argumen. Konteks yang menguap begitu sesi ditutup. Alat yang bagus tapi belum jadi sistem.

Kalau Anda mengangguk membaca ini, framework ini mungkin juga untuk Anda.

## Jujur di awal

Sebelum lanjut lebih jauh, saya mau jujur dulu.

ARTi Framework ini masih terus berkembang. Bukan produk jadi yang sudah final dan tidak berubah lagi.

Saya masih menambah, mengubah, dan memperbaiki bagian-bagiannya sampai sekarang, termasuk sambil menulis buku ini.

Tapi satu hal yang sudah saya buktikan sendiri: framework ini benar-benar menyelesaikan masalah saya. Halusinasi berkurang drastis. Memori tidak lagi menguap setiap sesi baru dibuka.

Jadi meskipun belum sempurna, ini bukan sekadar ide di atas kertas. Ini sesuatu yang saya pakai sendiri, setiap hari.

## Tiga lapis makna

Nama "ARTi" sendiri bukan saya pilih asal.

Ada tiga lapis makna di baliknya, dan ketiganya sekaligus menjadi filosofi framework ini.

Mari saya jelaskan satu-satu di bagian berikutnya.
