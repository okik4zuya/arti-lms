# Skill

Dipakai setelah satu tahap selesai. Ubah gesekan jadi perbaikan skill atau tool, di sesi terpisah.

## Usul perbaikan

```text
Berdasarkan pengalaman ini, usulkan perbaikan di skill [NAMA].
```

```text
Apakah selama [TAHAP] ada skrip atau micro-workflow baru yang
tidak dicover [SKILL]? Sebaiknya ditambahkan di skill atau tool?
```

```text
Berdasarkan preferensi ini, update skill [NAMA] soal [TOPIK].
Setelah itu lanjutkan proyek.
```

## Rencana, lalu jalankan

```text
Buat plan untuk perbaikan skill di ~/.arti/skills.
```

Di sesi baru:

```text
Implement plan: [PATH plan]
```

## Preferensi

```text
Tambahkan preferensi: [ATURAN].
```

```text
Salin perubahan ini ke semua proyek paper yang sedang berjalan.
```

## Rekap koreksi (saran)

```text
Dari sesi ini, daftar semua tempat saya mengoreksi kamu. Mana
yang layak jadi aturan tetap, dan di berkas mana ditulis?
```

## Cek duplikat (saran)

```text
Sebelum mendesain perbaikan, cek dulu apakah sudah ada di skill
atau tool. Tunjukkan baris yang relevan.
```

## Uji perubahan (saran)

```text
Uji perubahan skill [NAMA] di proyek [PROYEK]. Laporkan lulus
atau gagal per butir; jangan memperbaiki apa pun.
```

## Dampak (saran)

```text
Apa yang berubah bagi proyek yang sedang berjalan kalau skill ini
diubah? Berkas mana yang harus disesuaikan?
```

Lanjut bila: perubahan skill diuji di satu proyek sebelum disalin ke yang lain.
